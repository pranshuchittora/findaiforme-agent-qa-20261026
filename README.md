# FindAIForMe

免费 / freemium AI 工具导航站。

- 官网：[https://findaifor.me/](https://findaifor.me/)
- 收录约 **9,364** 个 AI 工具、**12** 个分类
- 支持中英切换，可提交工具
- 浅色目录站，按需求搜索（例如「视频翻译 AI 工具」）
